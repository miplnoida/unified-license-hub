## Phase 6 — Error-swallowing census (partial, carried)
333 `const { data } = await …` sites (153 files) discard the PostgREST error, and
376 `from('x' as any)` casts bypass the generated types. Every schema defect
above reached production through that combination. Architectural remedy adopted:
the reusable contract gate (Phase 10) verifies columns, embeds, write payloads
and RPC signatures regardless of `as any`, so masked drift now fails CI instead
of degrading a screen silently. Per-site conversion of swallowed errors to
surfaced errors is recorded as follow-on debt, not a schema defect.
